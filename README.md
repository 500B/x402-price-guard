# x402-price-guard

A realistic, multi-party test environment for x402 agent payments, built so that a price guard can later be installed into one slot and verified against honest and adversarial sellers with ground truth taken from the chain. Version 1 is the environment only; the guard comes later.

Status: design complete, implementation not started.
